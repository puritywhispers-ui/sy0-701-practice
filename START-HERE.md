# Open the quiz in a website

GitHub is not the quiz. You still need to upload `index.html` and turn on Pages.

## Fast path

1. Download SY0-701-Live-Exam.html
2. Rename it to index.html
3. In this repo click Add file → Upload files
4. Upload index.html and commit
5. Settings → Pages → Deploy from a branch → main → / (root) → Save
6. Wait 2 minutes
7. Open https://puritywhispers-ui.github.io/sy0-701-practice/
