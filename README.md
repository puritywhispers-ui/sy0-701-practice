Interactive 90-question CompTIA Security+ (SY0-701) practice test with **instant grading and explanations**.

## Take the test

Download [index.html](./index.html) and open it in any browser. Click **Start exam**, choose A-D, and the correct answer plus explanation appear immediately.

Keyboard: A-D to answer, Enter or N for next.
